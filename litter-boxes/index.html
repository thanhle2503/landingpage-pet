Pet.Picks notes: which box fits which home

How we would choose, based on what each brand publishes.

Several cats: a self-cleaning box keeps up between scoops, so it suits homes with two or more cats.

Small spaces: check the box's height and footprint before you buy.

Shy cats: leave the old box next to the new one for a week while your cat gets used to it.

Questions, answered

Short answers based on what each brand lists on its product pages.

Is a self-cleaning litter box worth it?

If you scoop every day or have several cats, it saves time and keeps odour down. It costs more up front than a plain box.

Do cats get used to a self-cleaning box?

Most do within a few days. Keep the old box nearby at first and run the cleaning cycle only after your cat has left.
